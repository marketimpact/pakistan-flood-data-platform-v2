# Contributing to Pakistan Flood Data Platform

Thank you for your interest in contributing to the Pakistan Flood Data Platform!

## Code of Conduct

We expect all contributors to maintain professional conduct and respect for all participants.

## How to Contribute

1. **Fork the Repository**
   - Create your own fork of the project
   - Clone it locally: `git clone https://github.com/YOUR-USERNAME/flood-data-platform.git`

2. **Create a Branch**
   - Create a feature branch: `git checkout -b feature/your-feature-name`
   - Or a bugfix branch: `git checkout -b fix/issue-description`

3. **Follow TDD Principles**
   - Write tests first for any new functionality
   - Ensure all tests pass before submitting
   - Maintain or improve code coverage

4. **Code Style**
   - Follow PEP 8 for Python code
   - Use meaningful variable and function names
   - Add docstrings to all functions and classes
   - Keep functions small and focused

5. **Commit Messages**
   - Use clear, descriptive commit messages
   - Start with a verb: "Add", "Fix", "Update", "Remove"
   - Reference issue numbers when applicable

6. **Submit a Pull Request**
   - Push your branch to your fork
   - Create a pull request with a clear description
   - Link any related issues
   - Wait for code review

- **Bug Fixes**: Check GitHub issues for reported bugs
- **Documentation**: Improve or translate documentation
- **Tests**: Increase test coverage
- **Features**: Discuss new features in issues first
- **Performance**: Optimize database queries or API calls
